\# Cloud Platform Lab



A hands-on platform engineering project, built from scratch, phase by phase:

containerization → Kubernetes → CI/CD with GitOps → observability → cloud security.



\*\*Status:\*\* Phase 1 — Containerization (Docker fundamentals, multi-stage builds)



\## Principles

\- Everything as code, everything reproducible

\- Local-first (kind) to keep costs at zero; AWS resources are ephemeral (create → validate → destroy)

\- No employer data: built entirely from scratch
